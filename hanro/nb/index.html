Hanro - Inntekt for sjåfører

Gig-inntekt, km og utgifter

Last ned i App Store

Hanro er inntektsappen for gig-sjåfører – matlevering, budlevering, drosje og persontransport.

Logg inntekter på tvers av plattformer med ett trykk. Hanro beregner automatisk timelønn og km-sats ut fra aktive timer og kjørt distanse. AI-prognoser for beste kjøretider og skattklar dataeksport hjelper deg å tjene mer.

FUNKSJONER

Støtte for flere plattformer

  • Kompatibel med store mat- og budleveringsplattformer som Uber Eats; legg til egne tjenester fritt
  • Visualisering av inntekter, antall leveringer og timelønn per plattform

Automatisk km-registrering

  • Core Motion + Core Location registrerer kjøring automatisk
  • Bluetooth-kobling til kjøretøy identifiserer start og slutt på arbeidsøkt
  • Automatisk fordeling mellom jobb-km og privat-km

AI-prognose for topp-tider

  • Apple Intelligence analyserer ukedag, klokkeslett og vær
  • Månedlig gjennomgang foreslår de mest lønnsomme tidene neste måned

Skattklar dataeksport

  • CSV-format for freee, MoneyForward og Yayoi (japansk regnskapsprogramvare)
  • Automatisk fradragsberegning (jobb-km / total-km)
  • Tilpasset japanske regler for kvalifisert faktura og elektronisk bokføring

Utgiftsstyring

  • Skann kvitteringer → AI-kategorisering (VisionKit + Foundation Models)
  • Spor kjøretøy-, drivstoff-, kommunikasjons- og andre utgifter
  • Månedlig PDF-rapport

Helt offline

  • Alle funksjoner kjører på enheten
  • Ingen data forlater telefonen
  • Valgfri iCloud-synkronisering på tvers av enheter

Apple Watch

  • Logg leveringer med ett trykk fra håndleddet
  • Store knapper beregnet for bruk under kjøring

Widgeter og Live Activities

  • Dagens inntekt og månedlig fremgang på startskjermen
  • Aktive økter på låseskjermen
