Hanro

配達ドライバーの稼ぎが、ひと目でわかる

フードデリバリー・軽貨物・タクシードライバーのための、完全オフラインで使える売上 & 経費管理アプリ。マルチプラットフォーム対応、スクリーンショットからの売上取込、手取りシミュレーション、確定申告データ出力をすべて 1 つのアプリで。

使い方（3ステップ）

  1. 売上・経費を記録する
  2. 走行距離を記録し、業務／私用をスワイプで仕分ける
  3. 確定申告用CSVを出力する

アプリの画面

配達ドライバーの収支管理ができる主な機能

マルチプラットフォーム対応

Uber Eats / 出前館 / Wolt / menu / Amazon Flex / ピックゴー など、複数の配達サービスをまたいだ売上を一元管理。

スクリーンショットから売上取込

配達アプリの売上画面を共有シートから渡すだけで、金額を読み取って記録。手入力の取りこぼしを防ぎます。

走行距離の記録

Core Motion + Core Location で業務開始から終了までの距離を計測。業務 km と私用 km はスワイプで業務／私用を仕分け、家事按分に反映。運転の自動検知は設定から有効にすると動作します（プレミアム）。

手取りシミュレーション

今年の実績から所得税・住民税・国民健康保険・国民年金の概算を算出し、売上ベースの時給と「手取り換算時給」を並べて表示。

稼ぎ時予測

同じ曜日・時間帯の過去実績から時給を推定して稼働中に表示。収益マップで稼げたエリアを地図上に可視化（プレミアム）。

確定申告データ出力

freee / マネーフォワード / 弥生会計 の CSV フォーマットに対応。対象年を選んで出力するので前年分が混ざりません。家事按分も自動計算。

レシート OCR

レシートを撮影すると金額・店舗を読み取り、科目を自動選択（プレミアム）。科目別の月次レポートを PDF 出力。

国交省様式の帳票

運転日報 PDF を日付単位で出力。事故・ヒヤリハット報告書 PDF と、行政への報告義務の簡易判定にも対応。

車両管理

車検期限・オイル交換時期をローカル通知でお知らせ。給油記録から区間燃費・平均燃料単価を算出。

完全オフライン動作

すべての処理を端末内で完結。当方のサーバーへの送信はありません。iCloud にサインインしていれば、お使いの端末間で同期されます。

Apple Watch 対応

手元のワンタップで配達を記録。大型ボタンで運転の合間でも扱いやすい設計。

ウィジェット / ライブアクティビティ / Siri

今日の売上・月間目標進捗をホーム画面に表示。稼働中のセッションはロック画面とコントロールに表示。「Hanro で業務開始」など Siri からも操作できます。
