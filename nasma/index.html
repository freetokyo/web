一日ずつ、澄んだ呼吸へ。

紙巻きたばことシーシャ（水たばこ）を、それぞれの単位で記録するアプリです。
浮いたお金と時間、そして吸わなかった日数を並べて見せます。

iPhone / iOS 18.0 以降・日本語 / English / العربية・アカウント登録不要・通信ゼロ

シーシャを、シーシャとして数える

セッション単位で記録

回数だけでなく、時間・フレーバー・場所まで残せます。多くの禁煙アプリはシーシャを記録単位として持っていません。

単一換算はしません

「1セッション＝紙巻き◯本」という表示は採用していません。吸入する煙の量・一酸化炭素・ニコチンは倍率が大きく異なるためです。

指標ごとに、出典つきで

指標を分けてレンジで示し、出典を併記します。表示が不要なら設定でオフにできます。

ラマダンと、ヒジュラ暦の生活リズム

断食時間中の断煙を集計

断食の開始・終了時刻を設定すると、その時間帯に記録がなかった時間を積み上げます。位置情報は使いません。

地域の発表に合わせられる

暦の計算値は地域の発表と前後することがあります。開始日を1日ずらす設定を用意しています。

ラマダンの後も

断食期間に作れた間隔は、その後も続けられます。戻りやすい場面を「きっかけ」として記録できます。

見られたくない、を前提に設計する

生体認証ロックは無料

秘匿性を最も必要とする人に課金の壁を作らないため、ロックは無料で使えます。

通知に喫煙の語を出さない

通知の既定の文言には、無料・フルアクセスを問わず、たばこやシーシャに関する語が含まれません。

ウィジェットも中立表示に

プライバシーモードをオンにすると、ウィジェットと Apple Watch は日数や金額を出さず中立的な表示になります。

記録は、あとから直せてこそ

追加・編集・削除・取り消し

1タップ記録には取り消しがあります。過去の日時でも入力でき、件数に上限はありません。

検索と絞り込み

フレーバー・メモ・場所・種別で絞り込めます。

バックアップと復元

JSON で書き出し、読み込みで戻せます。書き出しだけの「バックアップ」ではありません。

からだの経過は、出典とともに

20分後・12時間後・1日後…と、一般に知られている経過を段階で紹介します。出典を必ず併記し、経過には個人差があることを明記しています。これは診断・治療・予防を目的としたものではありません。体調について気になることがあるときは医師にご相談ください。

よくある質問

通信は本当にゼロですか？

はい。アカウント登録はなく、記録は端末内にのみ保存されます。外部への送信はありません。広告も第三者の解析も入れていません。

シーシャだけを記録できますか？

できます。最初の設定で「シーシャ（水たばこ）」を選ぶと、紙巻き用の入力欄は表示されません。あとから設定で変更できます。

吸ってしまった日も記録していいのですか？

はい。「連続」と「累計」を分けて表示するので、記録しても累計はゼロに戻りません。責める表現は使っていません。

機種変更するとデータはどうなりますか？

端末内にのみ保存されるため、そのままでは引き継がれません。フルアクセスのバックアップ機能で JSON を書き出し、新しい端末で読み込んでください。

ヘルスケアのデータは何に使われますか？

安静時心拍数・歩数・睡眠の3種類だけを読み取り、同じ期間の推移を並べて表示します。読み取り専用で、書き込みは行いません。端末内で処理し、外部には送信しません。

サブスクリプションですか？

いいえ。買い切りです。一度購入すれば追加の料金はかかりません。

健康情報についての注記

本アプリが表示する健康に関する内容は、一般に知られている経過の紹介であり、出典を併記しています。診断・治療・予防を目的としたものではなく、禁煙の成否や治療上の効果を示すものでもありません。経過には個人差があります。体調について気になることがあるときは医師等の専門家にご相談ください。
