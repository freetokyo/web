Getting started

  1. Add a bean — tap + in the Beans tab and enter the name, origin and purchased weight.
  2. Start roasting — from Home, pick the bean and charge weight (optionally a charge temperature and a target profile), then tap Charge.
  3. While roasting — tap Temperature, Dry End, First Crack, First Crack End, Second Crack, Operation and Drop. A mistap can be undone for five seconds.
  4. After the roast — enter the roasted weight, roast level and tasting notes; weight loss is computed automatically.
  5. Repeat it — turn on "Mark as target profile" in the batch detail, and pick it as a target next time (Pro).

FAQ

I don't have a thermometer. Can I still use it?

Yes. Every temperature entry is optional — use "Record without temperature" to log an event by time alone. With first crack and drop, DTR is still calculated.

How do I switch to Fahrenheit?

Settings tab → Units. Readings are stored normalized internally, so past roasts stay comparable when you switch.

The ghost curve doesn't appear

The ghost curve is a HazeLog Pro feature. Also, only a saved roast with "Mark as target profile" turned on can be used as a target. Save one roast first, then mark it.

The screen turns off while roasting

Auto-lock is disabled while the roasting screen is open, and returns to normal when you leave it or switch apps.

I can only add three beans

The free tier allows three beans. A fourth and beyond unlock with the one-time HazeLog Pro purchase.

I purchased Pro but it isn't active

Try "Restore Purchase" in the Settings tab or on the paywall. You must be signed in with the same Apple ID used for the purchase.

How do I back up my roasts?

Use Export (Settings tab, or the button at the top right of a batch detail) to write CSV or PDF. Pro required.

My data disappeared

Records live only on your device, so deleting the app removes them permanently. Regular exports are recommended.
