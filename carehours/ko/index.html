CareHours 방문요양 급여계산·기록

야간·휴일가산/이동시간/PDF·CSV 출력

App Store에서 다운로드

CareHours(케어아워즈)는 방문요양 요양보호사·재가 요양보호사를 위한 요양 기록·급여계산 앱입니다.

이런 분께 추천

  • 방문요양보호사로 여러 이용자 댁을 방문하는 분
  • 여러 기관을 겸업하며 수입을 기관별로 파악하고 싶은 분
  • 실적 기록을 손으로 쓰거나 Excel로 관리해 번거로움을 느끼는 분
  • 야간가산·휴일가산을 포함한 급여계산을 정확히 하고 싶은 분
  • 매달 PDF 실적표를 기관에 제출하는 분

주요 기능

한 번의 탭으로 방문 기록 시작·종료

방문 시작 때 탭만 하면 됩니다. 이용자를 선택하고 「방문 시작」을 누르면 기록이 시작됩니다. 방문 종료 시 서비스 종류(신체 지원·생활 지원 등)와 메모를 입력해 저장. 복잡한 조작은 전혀 필요 없습니다.

예상 급여를 자동 계산

시간 단가·야간가산(22시~6시)·휴일가산을 설정하면 방문 종료 직후 예상 급여가 자동으로 계산됩니다. 이동 시간을 급여에 포함하는 설정도 지원. 일본 공휴일(2025~2027년 대응)도 자동 판정해 월간 수입을 실시간으로 파악할 수 있습니다.

여러 이용자 관리·서비스 종류별 단가

이용자별로 이름·요양 서비스 구분·시급을 등록. 신체 지원과 생활 지원의 단가가 다른 경우에도 서비스 종류별 단가를 설정할 수 있습니다. 여러 기관·이용자를 한곳에서 관리할 수 있습니다.

기관별 집계(겸업에 편리)

여러 기관을 겸업하는 분을 위해 월간 리포트에서 기관별 수입 합계를 확인할 수 있습니다. 소득 신고나 급여 대조 시 유용합니다.

실적 기록·방문 이력 확인

지난 방문 기록을 월별로 확인. 이용자로 필터링도 가능합니다. 기록의 편집·수정도 가능하며, 급여는 수정 후 자동으로 다시 계산됩니다.

PDF·CSV 출력으로 보고서 작성을 효율화

월간 실적을 PDF 형식으로 출력. A4 레이아웃으로 기관 제출용 보고서로 활용할 수 있습니다. CSV로 Excel 관리도 가능합니다.

※PDF·CSV 내보내기는 Premium 플랜 기능입니다.

iCloud로 안심 백업

모든 기록은 iCloud에 자동 동기화. 기기 변경 시에도 데이터를 이어받을 수 있습니다. 오프라인 환경에서도 기록할 수 있습니다.

Premium 플랜

월정액 또는 연간 구독 (App Store에서 가격 확인)

  • 월간 기록 건수: 무제한(무료 버전은 월 10건까지)
  • PDF·CSV 출력: 이용 가능
  • 워터마크 없음

무료 버전에서 할 수 있는 것

  • 이용자 등록: 무제한
  • 방문 기록: 월 10건까지
  • 급여 자동 계산·실적 확인: 이용 가능
