Getting started

Do I need to create an account?
No. TsukiLift works fully without an account. It never asks for an email address or any personal details.
Is HealthKit (Apple Health) integration required?
It is optional. If you decline or skip HealthKit integration, you can still use every feature of the app, including period logging, workouts, BBT, body composition, and symptom logs. You can change the setting at any time under "Settings → HealthKit Integration".
Where is my data stored?
Only on your iPhone. Nothing is ever sent to an external server or the cloud. iCloud sync is not used either, so moving to a new device requires a manual export and import.
Can I move my data to a new device?
Yes. Save a JSON file from "Settings → Data Management → Export", then import that file on the new device. This feature is free.

Cycle tracking

How is the cycle prediction calculated?
The app averages your past records to estimate your cycle length and predict the next start date. Accuracy is lower when there are few records. It is a reference trend, not a medical diagnosis.
Can I use it to identify ovulation or to make contraception or pregnancy decisions?
No. This app is not a tool for identifying ovulation or for contraception or pregnancy decisions. What it shows are cycle trends, and it cannot be used for medical decisions. Please consult a doctor or another qualified professional for those purposes.
I use hormonal contraception (such as the pill). Does that affect anything?
If you turn on "Settings → Using hormonal contraception", a note is shown alongside cycle phase predictions to indicate that they are reference values. Because hormonal contraception changes the cycle, prediction accuracy may be lower than usual.

Workout logging

Can I customize exercises?
Yes. In addition to the built-in exercise catalog, you can add your own. Creating and saving workout templates lets you recall your favorite exercise sets quickly (unlimited templates are a Premium feature).
How is estimated 1RM (one-rep max) calculated?
The app applies a common estimation formula to your logged set data (weight, reps, RPE). It is a reference value and may differ from your actual one-rep max.

Data management

How do I back up my data?
From "Settings → Data Management → Export" you can export all data as JSON or CSV. Keep the exported file somewhere safe of your choosing (iCloud Drive, the Files app, and so on). This feature is free.
I want to delete all of my data
You can do that from "Settings → Data Management → Delete all data". This action cannot be undone, so we recommend exporting a backup first.
Will my data be lost if I uninstall the app?
Yes. Because data is stored locally on your device, deleting the app erases all of it. Please export a backup before uninstalling.

Premium and billing

How much can I do on the free plan?
All logging features — period, workouts, BBT, body composition, and symptom logs — plus the calendar view and data export and import are free. Premium adds advanced analysis reports and unlimited workout templates.
How do I cancel Premium?
On your iPhone, go to "Settings" → "Apple ID (your name)" → "Subscriptions" → "TsukiLift" → "Cancel Subscription". Cancellation takes effect from the next renewal date. Deleting the app alone does not cancel the subscription.
How do I request a refund?
Refunds for App Store purchases follow Apple's policy. Please request one via Apple's support page (reportaproblem.apple.com). We are not able to process refunds directly.
