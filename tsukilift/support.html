はじめかた

アカウント登録は必要ですか？
不要です。TsukiLift はアカウントなしで完全に利用できます。メールアドレスや個人情報の登録は一切求めません。
HealthKit（Apple ヘルスケア）との連携は必須ですか？
任意です。HealthKit 連携を拒否・スキップしても、生理記録・筋トレ・BBT・体組成・症状ログなど、本アプリのすべての機能をご利用いただけます。連携設定はいつでも「設定 → HealthKit 連携」から変更できます。
データはどこに保存されますか？
お使いの iPhone 内のみに保存されます。外部サーバーやクラウドへの送信は一切行いません。iCloud 同期も使用していないため、機種変更時は手動でのエクスポート・復元が必要です。
機種変更時にデータを引き継げますか？
「設定 → データ管理 → エクスポート」から JSON ファイルを保存し、新しい端末でそのファイルをインポートすることでデータを引き継げます。この機能は無料でご利用いただけます。

生理周期トラッキング

生理周期の予測はどのように計算されますか？
過去の記録をもとに平均周期を算出し、次の生理開始日を予測します。記録が少ない場合は精度が低くなります。あくまで傾向の参考値であり、医学的な診断ではありません。
排卵日の特定や避妊・妊娠の判断に使えますか？
本アプリは排卵日の特定や、避妊・妊娠の判断を目的としたツールではありません。表示される情報は生理周期の「傾向提示」であり、医療上の判断には使用できません。これらの目的には医師・専門家にご相談ください。
ホルモン避妊法（ピルなど）を使用していますが、影響はありますか？
「設定 → ホルモン避妊法を使用中」をオンにすると、周期フェーズ予測に参考値である旨の注意書きが表示されます。ホルモン避妊法の使用中は周期が変化するため、予測精度が通常より低くなる場合があります。

筋トレ記録

種目はカスタマイズできますか？
はい。内蔵の種目カタログに加え、オリジナルの種目を追加できます。トレーニングテンプレートを作成・保存しておくことで、よく使う種目セットをすばやく呼び出せます（無制限テンプレートはプレミアム機能です）。
1RM（最大挙上重量）の推定はどう計算されますか？
記録したセットのデータ（重量・回数・RPE）をもとに、一般的な推定式を用いて 1RM を計算します。あくまで参考値であり、実際の最大挙上重量とは異なる場合があります。

データ管理

データをバックアップする方法は？
「設定 → データ管理 → エクスポート」から、全データを JSON または CSV 形式でエクスポートできます。エクスポートファイルをご自身の安全な場所（iCloud Drive・Files アプリ等）に保存してください。この機能は無料です。
全データを削除したい
「設定 → データ管理 → 全データを削除」から削除できます。この操作は取り消せません。削除前にエクスポートでバックアップを取ることをお勧めします。
アプリをアンインストールしたらデータは消えますか？
はい。データはデバイス内のローカルに保存されているため、アプリを削除するとすべてのデータが消去されます。アンインストール前にエクスポートでバックアップを取ってください。

プレミアム・課金

無料版でどこまで使えますか？
生理記録・筋トレ記録・BBT・体組成・症状ログのすべての記録機能、カレンダー表示、データエクスポート・インポートが無料でご利用いただけます。プレミアム機能は、高度な分析レポートと無制限のトレーニングテンプレートです。
プレミアムの解約方法は？
iPhone の「設定」→「Apple ID（お名前）」→「サブスクリプション」→「TsukiLift」→「サブスクリプションをキャンセルする」から解約できます。解約は次の更新日より有効になります。アプリの削除だけでは解約されません。
返金を希望する場合はどうすればいいですか？
App Store での購入に対する返金は、Apple のポリシーに準拠します。Apple サポートページ（reportaproblem.apple.com）からご申請ください。本アプリでは返金処理を直接行うことができません。
