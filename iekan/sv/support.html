Support

実家管理 IeKan-親の家を家族で見守る

Hur börjar jag använda gratis?
Ladda ner IeKan från App Store. Ingen kontoregistrering krävs. För familjedelningsfunktionen, logga in på iCloud.
Hur bjuder jag in familjemedlemmar?
Gå till Inställningar → Bjud in familj för att visa en 6-teckens inbjudningskod. Dela den via meddelande. Familjemedlemmar går med genom att ange koden via Gå med med inbjudningskod i appen.
Hur registrerar jag en fastighet?
Tryck på + i det övre högra hörnet av hemskärmen. Ange fastighetens namn, adress och byggår. Gratisplan: 1 fastighet; flera fastigheter kräver en premiumplan.
Jag kan inte ladda upp bilder
Gratisplanen tillåter upp till 50 bilder per fastighet. Radera äldre bilder eller uppgradera till premium för obegränsat lagringsutrymme. Lågt lagringsutrymme på enheten kan också förhindra uppladdningar.
Hur fungerar jämförelsen före/efter?
Välj 2 bilder på bildtidslinjen för att jämföra dem sida vid sida. Det hjälper dig att följa förändringar över tid.
Hur tar jag bort ett foto?
Håll in ett foto på tidslinjen för att se raderingsmenyn. Raderade foton kan inte återställas.
Hur använder jag de säsongsmässiga checklistorna?
Checklistefliken har förinställda mallar för Vår, Sommar, Höst, Vinter och Månadsvis. Tryck på varje kryssruta för att markera den som klar. Historiken registreras i 24 sessioner och kan visas som ett diagram.
Kan jag lägga till anpassade checklistobjekt?
Ja. Tryck på +-knappen på checklisteskärmen. Gratisplan: upp till 5 anpassade objekt; premiumplan: obegränsat.
OCR läser inte bra
Prova: fotografera i starkt ljus, justera avstånd så att hela dokumentet syns på skärmen, håll dokumentet plant, håll enheten stilla. Text och datum extraherade av OCR är bara vägledande — kontrollera alltid själv.
Jag har nått den månatliga gränsen på 3 skanningar
Gratisplanen tillåter 3 dokumentskanningar per månad. Gränsen återställs i början av nästa månad. Uppgradera till premium för obegränsade skanningar.
