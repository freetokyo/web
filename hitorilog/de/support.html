Support

HitoriLog

Ist die Nutzung kostenlos?
Protokollierung, private Notizen und Grafiken (letzte 30 Tage) sind kostenlos nutzbar. PDF-Export, CSV-Export, Verlaufsgrafiken, iCloud-Backup und App-Sperre werden mit einem Einmalkauf freigeschaltet (kein Abonnement).
Ich möchte meinen Kauf wiederherstellen
Tippen Sie auf den Tab "Einstellungen" → "Käufe wiederherstellen". Wenn Sie mit derselben Apple-ID angemeldet sind, kann er wiederhergestellt werden.
Wo werden meine Daten gespeichert?
Alles wird nur auf Ihrem iPhone gespeichert. Es findet keine Übertragung oder Erfassung von Daten an externe Server statt, und es ist keine Kontoregistrierung erforderlich.
Was ist das iCloud-Backup?
Die Premium-Funktion iCloud-Backup sichert Ihre Daten automatisch in Apples privater Datenbank. Es kann für den Zugriff auf Daten auf anderen Geräten oder für die Datenmigration bei einem Gerätewechsel verwendet werden. Es wird niemals mit Familie oder anderen geteilt.
Ich kann kein PDF exportieren
Der PDF-Export ist eine Premium-Funktion. Bitte kaufen Sie ihn unter "Einstellungen" → "Premium freischalten". Falls Sie ihn bereits gekauft haben, versuchen Sie "Käufe wiederherstellen".
Wie entsperre ich die App-Sperre?
Die App-Sperre kann durch Face ID / Touch ID-Authentifizierung entsperrt werden. In Umgebungen, in denen biometrische Authentifizierung nicht verfügbar ist, wird die Sperre automatisch aufgehoben. Sie können sie unter "Einstellungen" → "App-Sperre" ein-/ausschalten.
Ich habe versehentlich einen Eintrag gelöscht
Gelöschte Einträge können nicht rückgängig gemacht werden. Wenn Sie das iCloud-Backup (Premium) aktiviert haben, können Sie Ihre Daten beim Gerätewechsel usw. wiederherstellen.
