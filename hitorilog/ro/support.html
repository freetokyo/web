HitoriLog

Este gratuit de utilizat?
Înregistrarea, notițele private și graficele (ultimele 30 de zile) sunt gratuite. Exportul PDF, exportul CSV, graficele pentru întreaga perioadă, backup-ul iCloud și blocarea aplicației sunt deblocate printr-o achiziție unică (fără abonament).
Vreau să-mi restaurez achiziția
Atingeți fila "Setări" → "Restaurare achiziții". Dacă sunteți conectat cu același ID Apple, aceasta poate fi restaurată.
Unde sunt stocate datele mele?
Totul este stocat doar pe iPhone-ul dvs. Nu există nicio transmitere sau colectare de date către servere externe, și nu este necesară nicio înregistrare de cont.
Ce este backup-ul iCloud?
Funcția premium de backup iCloud face automat backup pentru datele dvs. în baza de date privată a Apple. Poate fi utilizată pentru accesarea datelor pe alte dispozitive sau pentru migrarea datelor la schimbarea telefonului. Nu este niciodată partajată cu familia sau alte persoane.
Nu pot exporta un PDF
Exportul PDF este o funcție premium. Vă rugăm să o achiziționați din "Setări" → "Deblocare Premium". Dacă ați achiziționat-o deja, încercați "Restaurare achiziții".
Cum deblochez blocarea aplicației?
Blocarea aplicației poate fi deblocată prin autentificare Face ID / Touch ID. În medii unde autentificarea biometrică nu este disponibilă, blocarea este eliberată automat. O puteți activa/dezactiva din "Setări" → "Blocare aplicație".
Am șters accidental o înregistrare
Înregistrările șterse nu pot fi anulate. Dacă aveți backup-ul iCloud (premium) activat, vă puteți restaura datele la schimbarea dispozitivului etc.
