HitoriLog

可以免費使用嗎?
記錄、私密備忘及圖表(過去30天)可免費使用。PDF匯出、CSV匯出、全期間圖表、iCloud備份及應用程式鎖定需透過一次性購買(無需訂閱)解鎖。
我想恢復購買
點擊「設定」標籤 →「恢復購買」。如果您使用相同的 Apple ID 登入,即可恢復。
我的資料儲存在哪裡?
所有內容僅儲存在您的 iPhone 上。不會向外部伺服器傳輸或收集任何資料,也無需帳戶註冊。
什麼是 iCloud 備份?
高級版 iCloud 備份功能會自動將您的資料備份到 Apple 的私人資料庫。可用於在其他裝置上存取資料,或在更換手機時遷移資料。絕不會與家人或他人共享。
無法匯出 PDF
PDF 匯出是高級功能。請從「設定」→「解鎖高級版」購買。如果您已購買,請嘗試「恢復購買」。
如何解鎖應用程式鎖定?
應用程式鎖定可透過 Face ID / Touch ID 身分驗證解鎖。在無法使用生物辨識驗證的環境中,鎖定會自動解除。您可以從「設定」→「應用程式鎖定」中切換開關。
我不小心刪除了一筆記錄
已刪除的記錄無法復原。如果您啟用了 iCloud 備份(高級版),可以在更換裝置等情況下恢復資料。
