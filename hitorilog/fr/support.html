Assistance

HitoriLog

Est-ce gratuit ?
La saisie, les notes privées et les graphiques (30 derniers jours) sont gratuits. L'export PDF, l'export CSV, les graphiques sur toute la période, la sauvegarde iCloud et le verrouillage de l'application sont débloqués avec un achat unique (sans abonnement).
Je souhaite restaurer mon achat
Appuyez sur l'onglet "Réglages" → "Restaurer les achats". Si vous êtes connecté avec le même identifiant Apple, il peut être restauré.
Où mes données sont-elles stockées ?
Tout est stocké uniquement sur votre iPhone. Il n'y a aucune transmission ni collecte de données vers des serveurs externes, et aucune création de compte n'est requise.
Qu'est-ce que la sauvegarde iCloud ?
La fonctionnalité premium de sauvegarde iCloud sauvegarde automatiquement vos données dans la base de données privée d'Apple. Elle peut être utilisée pour accéder aux données sur d'autres appareils ou pour migrer les données lors d'un changement de téléphone. Elle n'est jamais partagée avec la famille ou d'autres personnes.
Je ne peux pas exporter en PDF
L'export PDF est une fonctionnalité premium. Veuillez l'acheter depuis "Réglages" → "Débloquer Premium". Si vous l'avez déjà acheté, essayez "Restaurer les achats".
Comment déverrouiller le verrouillage de l'application ?
Le verrouillage de l'application peut être déverrouillé par authentification Face ID / Touch ID. Dans les environnements où l'authentification biométrique n'est pas disponible, le verrouillage est automatiquement levé. Vous pouvez l'activer/désactiver depuis "Réglages" → "Verrouillage de l'application".
J'ai accidentellement supprimé un enregistrement
Les enregistrements supprimés ne peuvent pas être annulés. Si vous avez activé la sauvegarde iCloud (premium), vous pouvez restaurer vos données lors d'un changement d'appareil, etc.
