Политика конфиденциальности

ToScore ミニバス スコア記録

Последнее обновление: июня 2026 г. / Разработчик: freetokyo apps

Основные принципы

Toscore максимально уважает конфиденциальность пользователей. Все данные записей матчей хранятся только на вашем устройстве и никогда не отправляются наружу. Приложение не собирает никаких персональных данных.

Информация, хранимая приложением

Хранится только на устройстве: записи матчей, введённые пользователем; профили правил; информация о покупке.

Информация, которая НЕ собирается

Приложение не собирает: персональные идентификационные данные; местоположение/GPS; контакты или календарь; журналы поведения; рекламный идентификатор (IDFA).

Камера и фото (автоввод OCR)

В приложении есть опциональная функция OCR для автоматического ввода номеров и имён. Доступ к камере запрашивается только при использовании этой функции. Всё распознавание OCR выполняется на устройстве.

Сетевое взаимодействие

Все функции работают в офлайне без сетевого взаимодействия.

Экспорт и совместный доступ

Экспорт выполняется пользователем через стандартный лист обмена iOS.

Информация о покупке и оплате

Покупки обрабатываются через App Store Apple. Данные кредитных карт управляются Apple. Используется StoreKit 2.

Хранение и удаление данных

Данные хранятся только на устройстве. Удаление приложения стирает все данные без возможности восстановления.

Передача третьим сторонам

Поскольку приложение не собирает персональную информацию, нечего передавать третьим сторонам.

Конфиденциальность детей

Приложение не собирает персональные идентификационные данные. Никакая личная информация о детях намеренно не собирается и не передаётся.

Изменения политики

Любые изменения будут сообщены через обновление приложения или эту страницу.

Контакты

По вопросам конфиденциальности обращайтесь через страницу поддержки.
