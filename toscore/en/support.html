Can I use it offline?
Yes. Toscore provides all functions offline. Scoring, rule validation, playing-time verification, and export all work without network communication. You can use it worry-free even in gymnasiums without mobile signal.
Where is data stored?
All game records are stored only on your iPhone. Nothing is sent to the developer's servers or externally. Uninstalling the app deletes all data, so please backup important records using the export function.
Can this record be used as an official record?
This app is for unofficial/reference use only. It assists with team mutual timekeeping, youth development, and practice games. Official competition decisions always follow competition rules, tournament regulations, and referee judgment. Exported records also state 'unofficial/reference only'.
Can I change the rules settings?
Yes. On the rules settings screen, choose a preset (Standard / U15 / Mini-basketball Basic / Mini-basketball National Special / Custom). You can also edit time, timeouts, substitutions, scoring, fouls, roster, playing time, and arrows by logical group, then save them as custom profiles.
What is playing-time verification?
This function checks in advance whether the requirement for all players to participate (as in mini-basketball) is expected to be fulfilled. It displays players who haven't played and required slots, and verifies lineup validity before the quarter starts. Difficult situations are flagged as warnings (based on conservative approximation).
What if I make a recording mistake?
Use the Undo button on the live screen to immediately reverse the most recent record. On the history/correction screen you can undo or redo any record, and apply batch corrections for quarter mix-ups. All records are retained in append-only form and are not physically deleted.
Which iOS version is supported?
iOS 17.0 and later is supported. Updating to the latest iOS is recommended.
