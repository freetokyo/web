PrintSummary / プリサマ プライバシーポリシー

PrintSummary（日本語名: プリサマ）は、学校プリントの撮影、OCR による文字抽出、締切整理、提出管理を支援するアプリです。このページでは、アプリが扱う情報、保存場所、外部送信しない範囲、ユーザーが削除できるデータを説明します。

基本方針: 現在の実装確認範囲では、主要処理は端末内完結を前提としています。
対象データ: 画像、OCR テキスト、締切候補、提出状態、復習用情報、通知設定、購入状態。
外部送信: 独自クラウド同期、広告 SDK、第三者解析 SDK は前提にしていません。
Privacy and Data Handling

PrintSummary / Purisama Privacy Policy

PrintSummary, also referred to in Japanese as Purisama, helps users capture school handouts, extract text with OCR, organize deadlines, and manage submission status. This page explains what information the app handles, where it is stored, what is not transmitted externally, and what users can delete.

Core posture: Within the scope verified in the current implementation, core processing is intended to remain on-device.
Handled data: Images, OCR text, deadline candidates, submission status, review-related data, notification settings, and purchase status.
External transmission: The app is not designed around proprietary cloud sync, ad SDKs, or third-party analytics SDKs.

データの扱い

1. アプリが扱う情報

  • 撮影または読み込んだ学校プリント画像
  • OCR で抽出したテキスト
  • 締切日、持ち物、科目、提出状態、復習タグなどの整理情報
  • 通知設定、追加辞書、最近開いた履歴、購入状態などの端末内設定

2. 利用目的

  • プリント画像から文字を読み取り、締切や持ち物を整理するため
  • 保存済みプリントを検索、再確認、OCR 再処理するため
  • 締切前のローカル通知を表示するため
  • 無料枠と Premium 利用状態を端末内で管理するため

3. 権限

  • カメラ: 学校プリント撮影と端末内 OCR のために使用します。
  • 写真: 既存画像の読込と端末内 OCR のために使用します。
  • 通知: 締切前のローカル通知表示のために使用します。

How Data Is Handled

1. Information the app handles

  • School handout images captured or imported by the user
  • Text extracted through OCR
  • Organizing data such as deadlines, required items, subjects, submission status, and review tags
  • On-device settings such as notifications, added vocabulary, recent history, and purchase status

2. Purpose of use

  • To read text from handout images and organize deadlines or required items
  • To search, revisit, and reprocess saved handouts
  • To display local reminders before deadlines
  • To manage the free quota and Premium status on the device

3. Permissions

  • Camera: Used for capturing school handouts and running OCR on-device.
  • Photos: Used for importing existing images and running OCR on-device.
  • Notifications: Used for local reminders before deadlines.

保存・共有・削除

4. 保存場所

現在の実装確認範囲では、画像はアプリの Application Support 配下、OCR テキストや抽出候補などは端末内データストア、設定の一部は UserDefaults に保存されます。

5. 外部送信と共有

OCR 用画像や OCR テキストを外部 API に送信する前提ではありません。手動バックアップでは JSON エクスポートが可能ですが、これはユーザーが明示的に共有操作をした場合のみです。

6. データ削除と問い合わせ

「設定 > データ削除」から、保存済みプリント、OCR 結果、保存画像、誤抽出サンプル、追加辞書、最近開いた履歴などのローカルデータを削除できます。

Storage, Sharing, and Deletion

4. Storage location

Within the current implementation scope, images are stored under Application Support, OCR text and extraction candidates are stored in the on-device data store, and some settings are stored in UserDefaults.

5. External transmission and sharing

The app is not designed to send OCR images or OCR text to external APIs. Manual backup can export JSON, but only when the user explicitly chooses to share it.

6. Data deletion and contact

From Settings > Delete Data, users can remove local data including saved handouts, OCR results, stored images, extraction issue samples, added vocabulary, and recent history.
