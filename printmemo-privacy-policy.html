PrintMemo Privacy Policy

最終更新日: 2026-04-09

PrintMemo は、学校プリントの撮影、OCR 解析、締切整理を主な目的とするアプリです。本ポリシーは、PrintMemo がどのような情報を端末内で扱うか、どの情報を外部に送信しないかを説明します。

1. 基本方針

PrintMemo は、アカウント作成や独自サーバーへの保存を前提としていません。現在の方針として、独自サーバー送信、広告 SDK、外部解析 SDK、アカウント作成は行いません。コード上で確認できる範囲では、OCR と締切抽出を含む主要な処理はユーザーの端末内で完結します。

2. アプリが扱う情報

  • 撮影または読み込んだ学校プリント画像
  • OCR により抽出された文字情報
  • 締切日、持ち物、科目、提出状態、復習タグなどの整理情報
  • 通知設定、最近開いたプリント、追加辞書、課金状態などの端末内設定情報

3. 情報の利用目的

  • プリント画像から文字を読み取り、締切や持ち物を整理するため
  • 保存済みプリントを検索、再確認、再処理するため
  • 締切前のローカル通知を表示するため
  • 無料枠や買い切り Premium の利用状態を端末内で管理するため

4. 外部送信について

コード上で確認できる範囲では、PrintMemo は OCR 用の画像やテキストを外部 API に送信しません。独自クラウド同期、広告 SDK、第三者解析 SDK も利用しません。

5. 権限の利用

  • カメラ: 学校プリントを撮影して端末内で OCR 解析するために使用します。
  • 写真: 既存のプリント画像を読み込み、端末内で OCR 解析するために使用します。
  • 通知: 締切前のローカル通知を表示するために使用します。

6. 保存場所

コード上で確認できる範囲では、画像はアプリの Application Support 配下に保存され、OCR テキストや抽出候補などは端末内のデータストアに保存されます。一部の設定値は UserDefaults に保存されます。

7. バックアップと共有

アプリ独自の自動クラウド同期はありません。手動バックアップでは JSON ファイルを書き出すことができますが、これはユーザーが明示的に共有操作を行った場合に限られます。

手動バックアップにはメタデータや OCR テキストが含まれる可能性があります。保存画像そのもの、通知設定、最近開いた履歴、購入状態は含まれません。

8. 課金

PrintMemo は App Store の買い切り型 In-App Purchase を利用する場合があります。購入処理は Apple の StoreKit を通じて行われます。

9. データ削除

アプリ内の Settings から、保存済みプリント、OCR 結果、保存画像、誤抽出サンプル、追加辞書、最近開いた履歴などのローカルデータを削除できます。
