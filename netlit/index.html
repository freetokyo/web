Netlit（ネットリット）

水槽の「本当の水量」を出す。

すべての投与量は、そこから決まります。

淡水（熱帯魚・水草）専用です。海水は扱いません。通信を行わず、アカウント登録も要りません。

60cm規格水槽は、64.8 L ではありません

60×30×36cm を外寸のまま掛けると 64.8 L になります。そこからガラス厚・実際の水位・大磯砂6cm・レイアウト材3L を差し引くと、残るのはおよそ 48 L。26% の差です。

この分母がずれたまま「1/3 換水」も「1L あたり◯mg」も決めているのが、淡水アクアリウムのふつうの状態です。Netlit は最初にこの数値を確定させ、以後の計算をすべてその上に乗せます。

実効水量は、引き算の内訳ごと見せます

外寸・ガラス厚・水位までの高さ・底床の厚みと種類・レイアウト材・機材の占有体積を入れると、総容積から何がどれだけ引かれて実効水量になったのかを内訳で表示します。

底床プリセットの空隙率はすべて「推定値」と明記しています。焼成ソイルのように製品差が大きいものは、水を張る前に排水法で実測することをおすすめします。入力に矛盾があるとき（底床とレイアウト材の合計が総容積を超えるなど）は、数値を出さずに矛盾の場所を指摘します。

換水は「源水の値」まで入れて計算します

換水後の濃度は、現在値と換水率だけでは決まりません。足す水そのものに入っている量が効きます。水道水の硝酸塩は地域で大きく違うので、Netlit は初期値を決め打ちにせず、お住まいの水の値を入れていただく設計にしています。

源水の値が目標値以上のとき、換水では目標に到達できません。このとき Netlit は数値を出しません。「何%換水すればよいか」を返すのではなく、RO/DI 水の混合や目標値の設定し直しといった代替案を示します。

1回でどこまで下げてよいかは、あなたが決めます

「1回の換水は最大で何%まで」という上限は、水槽の状態と生体によって変わります。アプリが数値を断定する筋合いのものではないので、初回に 20〜80% の範囲でご自身に決めていただきます（あとから設定で変更できます）。

安全の表示は換水率だけを見ていません。新旧の水温差・pH差・KH差・TDS差も合わせて見て、注意・警告のときは必ず理由を文章で出します。

乾燥塩は、同時に入るイオンまで書きます

硝酸カリウム（KNO3）・リン酸二水素カリウム（KH2PO4）・硫酸カリウム（K2SO4）・硫酸マグネシウム七水和物（MgSO4·7H2O）に対応し、「何 g 入れると何 mg/L 上がるか」と「何 mg/L 上げたいから何 g」を双方向で計算します。

硝酸塩を上げるつもりで KNO3 を入れると、カリウムも同時に入ります。Netlit はこの副次イオンの増加量を必ず併記します。分子量は原子量から計算しており、丸めた定数を持ち歩きません。

市販の液体は、ラベルから逆算して登録します

製品名のプリセットは持ちません（他社の商標をアプリに持ち込まないためです）。代わりに、お手持ちのボトルのラベルから濃度を逆算するウィザードを用意しました。「◯Lに◯mLで◯mg/L」といった表記を入れると、以後その製品は実効水量に合わせた mL 数で計算されます。カルキ抜きも同じ方式で、ご自身の製品の希釈率を登録して使います。

計算したら、その場で記録になります

結果カードの中に記録ボタンがあります。画面遷移はありません。記録にはそのときの実効水量・計算式のバージョン・入力値・結果がスナップショットとして残ります。

だから、あとで水槽の構成を変えて実効水量が変わっても、過去の記録は書き換わりません。詳細画面では「当時 41.0 L（現在 44.2 L）」のように両方を表示します。水質記録は編集でき、すべての記録は削除と、削除の取り消しに対応しています。

水質は7項目、グラフで見ます

NO3 / PO4 / KH / GH / pH / TDS / 水温を記録できます。件数の上限はありません。推移は Swift Charts のグラフで確認できます。

硝酸塩がどのくらいの速さで溜まるか

測定値が2点以上たまると、換水を跨いだ区間を除いて日次の硝酸塩生成速度を推定し、いまの換水ペースを続けたときに落ち着く濃度（定常濃度）を予測します。

推定に足りるデータが無いときは、「該当なし」や「速度 0」とは表示しません。使える区間が何本あるかを示したうえで、あと何を記録すれば推定できるようになるかを案内します。

データの扱い

Netlit は通信を行いません。アカウント登録は不要で、開発者にデータは送信されません。解析 SDK・広告 SDK は組み込んでおらず、開発者が利用状況を知る手段はありません。

端末で iCloud バックアップが有効な場合、他のアプリと同じく Netlit のデータも Apple のバックアップに含まれます。そのバックアップを扱うのは Apple であり、Netlit ではありません。

全データのバックアップファイルの書き出しと復元は無料です。

やらないこと

  • 海水は扱いません。Ca / KH / Mg のバランスも CO2 の推定も、v1.0 の対象外です。
  • 魚病薬の投薬量は計算しません。
  • 魚種のデータベースを持ちません。
  • 市販製品のプリセットを持ちません。ご自身でラベルから登録していただく方式です。
  • 端末間の同期はありません。移行はバックアップファイルで行います。

ご確認ください

本アプリが示す数値は一般的な計算結果であり、獣医療的な助言ではありません。生体の状態・水槽の履歴・試薬の精度によって適切な値は変わります。換水や添加を行う前に、ご自身で水質を測定し、最終的な判断はご自身で行ってください。
