Genbalog - 現場写真PDF報告書

사진을 찍어 PDF를 만들려면?
프로젝트를 만들고 탭 → + 버튼으로 카메라/라이브러리에서 사진 추가 → 사진을 탭하여 캡션과 메모 편집 → 'PDF 만들기' 탭.
사진 편집이 저장되지 않을 때
닫기 전에 오른쪽 상단 '저장' 버튼을 탭하세요. × 버튼은 변경사항을 버립니다.
무료 버전에서 할 수 있는 것은?
월 5개 PDF, 최근 10개 프로젝트, 사진+어노테이션+음성 캡션. Pro = 무제한.
Pro를 해지하려면?
iOS 설정 → Apple ID → 구독 → Genbalog Pro → 취소. 갱신 24시간 전까지 취소하세요.
데이터는 어디에 저장되나요?
모든 데이터가 기기에만 저장. 외부 서버로 전송 없음. iCloud Backup 활성화 권장.
기기 변경 시 데이터 이전 가능?
iCloud 또는 iTunes Backup에서 복원. 구독: 동일 Apple ID로 구매 복원.
PDF에 로고를 추가하려면?
Pro 기능. Pro로 업그레이드 후 설정 → 회사 정보 → 로고 설정.
앱 언어를 바꾸려면?
설정 → 언어 → 일본어/영어/시스템. 즉시 적용.
음성 캡션이 인식되지 않음
iOS 설정 → 개인정보 → 음성 인식 → Genbalog 허용. 마이크 권한도 필요.
앱이 종료되거나 불안정함
완전히 종료 후 재시작. iOS와 앱 업데이트. 문제 지속 시 연락 바랍니다.
