현장 사진을 60초 만에 전문 PDF 보고서로.

1인 사업자, 기능공, 현장 관리자를 위한 현장 사진 보고서 앱입니다.

현장에서 사진을 찍고 캡션만 입력하면 A4 세로 레이아웃의 전문 품질 PDF가 60초 안에 완성됩니다. 카카오톡, 이메일, AirDrop으로 그 자리에서 바로 전송하세요.

이런 고민을 해결합니다

  • 보고서 작성에 1~2시간 → 60초면 완성
  • 월 5만 원 이상의 클라우드 비용 → 기본 무료
  • 폴더마다 흩어진 사진 → 섹션별 자동 정리
  • 매번 제각각인 레이아웃 → 통일된 전문 양식
  • 개인용 도구가 없음 → 1인 사업자에 최적화

주요 기능

현장 사진 정리

템플릿 섹션별(시공 전·시공 중·시공 후 / 이상 없음·주의·수리 필요)로 사진을 자동 분류합니다. GPS 정보와 촬영 시각도 자동으로 기록됩니다.

사진 주석

Apple Pencil이나 손가락으로 화살표·원·자유 곡선 주석을 추가하세요. 문제 부위를 타이핑 없이 직관적으로 표시할 수 있습니다.

음성 캡션 입력

마이크 버튼을 한 번 누르면 음성을 텍스트로 변환합니다. 두 손이 자유롭지 않은 현장에서도 빠르게 메모하세요.

전문 품질 PDF 생성

A4 세로, 2x2 그리드(페이지당 최대 4장)로 자동 생성. GPS 좌표·촬영 시각·캡션을 자동으로 삽입합니다. 사진 10장도 3초 이내에 생성 완료.

즉시 공유

카카오톡·이메일·AirDrop으로 현장에서 바로 전송. 파일 앱 저장도 지원합니다.

완전 오프라인 작동

클라우드 불필요, 회원가입 불필요, 로그인 불필요.

신호가 닿지 않는 지하·산간·공장 내부에서도 문제없이 사용할 수 있습니다.

모든 데이터는 사용자의 기기에 저장됩니다.

Pro 플랜(see pricing in App Store)

  • 모든 PDF 헤더에 회사 로고·상호 표시
  • 맞춤 템플릿(최대 6개 섹션 탭)
  • 모든 과거 보고서 보관 및 재전송
  • 사진·PDF 전체 ZIP 일괄 내보내기
  • 3일 무료 체험, App Store 설정에서 언제든 해지 가능
