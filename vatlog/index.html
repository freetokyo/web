Vatlog（ヴァットログ）

ビール・ワイン・サイダー・ミードを1つの台帳に記録し、その年に造った量の累計を自分で把握するための iOS / iPadOS アプリです。

年間の累計は、あなたが決めた目標に対して数える

瓶詰め日を基準に、その年の完成容量が積み上がります。目標を設定すれば進捗バーが出ます。設定しなければ進捗バーは描きません — 「0 / 未設定」のバーを見せても意味がないからです。

80% と 100% に達したときは、画面内に文言と記号を出します。色だけで状態を区別させません。ただし文面は「あなたが設定した目標を超えました」であって、それ以上のことは言いません。

このアプリは、何があなたに適用されるかを判定しません。家庭での発酵に関する規則は国・州・地域で異なり、時とともに変わります。Vatlog は記録と計算のためのツールであり、法的な助言を行うものではありません。

参考値は、出典と最終確認日をつけて「候補として」出す

米国とドイツについては、条文番号と最終確認日を添えた参考値を候補として提示します。採用するかどうかを決めるのは利用者です。

地域アプリが提示するもの出典
米国（連邦）ビール／ワインそれぞれの参考値。世帯の成人が1人か2人以上かで値が変わるため両方を並べて選ばせます（人数そのものは保存しません）26 U.S.C. §5053(e) / §5042(a)(2)(B)
米国（アラバマ州）酒種を合算した参考値と同時保有の値。州を選んだときだけ出ますAla. Code §28-4B-1
ドイツビールの参考値§29 Abs. 2 BierStG i.V.m. §41 BierStV
英国・オーストラリア・ニュージーランド・カナダ参考値を持ちません。「数量の上限は確認されていません」と画面に出し、自分で目標を入れる導線を出します—
日本年間累計のメーターを表示しません。酒税法第2条・第7条の注記に置き換えます酒税法

参考値のデータには版と最終確認日があり、設定画面に常時表示されます。参考値が更新されたときは「変わりました」と1度だけお知らせします。あなたが採用した値をアプリが勝手に書き換えることはありません。自分で入力した値には、この通知は出ません。

4種類を1つの台帳で

  • バッチ — ビール／ワイン／サイダー／ミード。計画中・発酵中・熟成中・瓶詰め済み・アーカイブの5状態
  • 発酵ログ — 日時・比重・温度・メモ。比重の推移はグラフになります
  • 原材料 — 発酵性原料／苦味付け／酵母／副原料／水調整。名称は自由入力で、過去に入れた名前から補完します
  • 酵母 — 使う酵母をご自身で登録して再利用できます（メーカーのデータベースは同梱していません）
  • テイスティングと写真

瓶詰めは専用の画面で行い、瓶詰め日と完成容量の両方が揃わないと確定できません。片方だけ入った状態を作らないためです。

計算機は9種類。すべてに出典を表示します

  • アルコール度数（標準式・高比重向けの式）
  • 比重の換算（SG ⇄ Brix ⇄ Plato）
  • 比重計の温度補正
  • 屈折計の補正（発酵中にアルコールがある状態）
  • 補糖
  • 苦味（IBU）
  • 色度（SRM / EBC）
  • プライミングシュガー
  • 単位換算（容量・温度・重量）

計算式の版はバッチごとに固定します。あとから設定で式を変えても、保存済みの記録の数値は変わりません。変えたければ、そのバッチで「現在の式で再計算」を押します。

公表されている式のみを実装し、第三者のデータセットは同梱していません。醸造の用語（SG・Brix・OG・FG・ABV・IBU・SRM など）は残したうえで、各計算機の「?」から用語の一覧を開けます。

書き出しと読み込み

  • JSON（無料）— バッチ・発酵ログ・原材料・テイスティング・目標。写真は含まれません
  • ZIP — JSON と写真の実体。機種変更のときはこちら
  • CSV — バッチ一覧と発酵ログの2種
  • PDF — バッチ1件1ページ。用紙は A4 と US Letter に対応し、地域から初期値を決めて設定で変更できます
  • JSON の読み込み — すでにある記録は消さず、無いものだけを追加します

PDF には、その記録が所有者の自己申告であって第三者の検証を受けていないこと、そして作成日時（端末時刻）と仕込み日（利用者の入力）の両方が印字されます。この注記は設定で消せません。

アカウントもサーバーもありません

Vatlog は自前のバックエンドを持たず、何も収集しません。記録は iOS がこの端末に保存します。起動後に権限ダイアログが1つも出ません — 位置情報・写真ライブラリ・通知のいずれも使わない設計です。地域は利用者が選ぶもので、位置情報から推定することはありません。

ただし端末の記録は iCloud バックアップに含まれます。「データが端末から出ない」とは書けないので、書けることだけを書いています。書き出したファイルは、共有した先で Vatlog の管理外に出ます。

単位と言語

容量・温度・糖度・重量はそれぞれ独立した設定です。地域から初期値を提案しますが固定はしません（米国在住でメートル法を使う方は珍しくありません）。小数点や日付の書式はお使いの言語に従います。

日本語・英語・ドイツ語。アプリ内で言語を切り替えられます（既定はシステムの言語）。

できないこと

  • クラウド同期はありません（サーバーを持たないため）
  • レシピの共有やコミュニティ機能はありません
  • スタイルガイドラインの数値レンジや、酵母メーカーのスペック一覧は同梱していません
  • 測定機器との連携はありません
  • アルコール分が基準を満たしているかどうかを、このアプリが判定することはできません
