Koegaki - Verbale Riunione

Trascrizione IA sul dispositiv

Scarica sull'App Store

Koegaki registra le tue riunioni e genera automaticamente trascrizioni, punti chiave, decisioni e attività—tutto sul tuo iPhone o iPad. Nessun cloud, nessun server.

Funzionalità

  • Registrazione nell'app (continua con schermo spento)
  • Trascrizione sul dispositivo (con timestamp)
  • Riepilogo IA in 3 sezioni: Punti chiave / Decisioni / Attività
  • Importa file audio esistenti
  • Modifica trascrizioni, riepiloghi e titoli
  • Ricerca testo completo
  • Esporta come Testo, Markdown o PDF

Acquisto unico (nessun abbonamento)

60 minuti gratis al mese. Acquista una volta per un uso illimitato.
